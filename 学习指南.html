一、11 阶段学习路径

第1阶段：文件操作基础（1-2天）

掌握 Linux 最基本的文件浏览和操作命令。

lscdpwdmkdirtouchcatrmcpmvechofindln

💡 试试 ls -la / 看根目录，再用 cd 探索。

第2阶段：文本处理（1天）

学会在终端里搜索和查看文件内容。

grepheadtailwcsortuniqcuttrsedawkdiffnlfilestat

💡 试试 grep root /etc/passwd。

第3阶段：系统信息与监控（2天）

了解服务器运行状态。

unamehostnamewhoamiidwhouptimedatefreepstophtopkilllsofdmesg

💡 htop 有彩色进度条，ps aux 列出所有进程。

第4阶段：硬件与磁盘（1-2天）

深入了解硬件和存储。

lscpulspcilsusblsblklshwdmidecodesmartctlsensorsdfdufdiskmountblkiddd

💡 smartctl -a /dev/sdb 查看坏道硬盘 SMART 详情。

第5阶段：网络（1-2天）

网络诊断和管理。

pingcurlwgetifconfigipnetstatssnslookupdigtracerouteroutetcpdumpncsshscp

💡 ping -c 5 8.8.8.8 看延迟变化。

第6阶段：用户与权限（1天）

Linux 用户管理系统。

chmodchownchgrpumaskuseradduserdelusermodpasswdsusudo

💡 sudo whoami 输出 root。

第7阶段：软件包管理（1天）

安装和管理软件。

aptyumdpkgsnap

💡 sudo apt install nginx 模拟完整安装过程。

第8阶段：服务管理（1天）

管理系统服务。

systemctljournalctlservicecrontab

💡 systemctl stop/start nginx 真实改变服务状态。

第9阶段：Shell 编程（2天）

环境变量、别名、脚本。

bashaliasenvexportsourceteewatch

💡 bash script.sh 支持变量和 $( ) 替换。

第10阶段：Vi/Vim 编辑器（1-2天）

终端编辑器。

vivimvimtutornano

💡 i 插入、Esc 普通、:wq 保存退出。

第11阶段：DevOps 工具链（3-5天）

学习现代运维工具。

dockerkubectlhelmmysqlredis-clinginxterraformansibleprometheusgrafanajenkinsgit

💡 在模拟器里 practice path docker/k8s/middleware/cicd 分路线练习。
