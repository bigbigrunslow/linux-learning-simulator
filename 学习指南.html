二、推荐学习路径

第1阶段：文件操作基础（1-2天）

掌握 Linux 最基本的文件浏览和操作命令：

ls cd pwd mkdir touch cat rm cp mv echo find ln

💡 试试 ls -la / 看看根目录下有哪些文件，然后用 cd 探索。

第2阶段：文本处理（1天）

学会在终端里搜索和查看文件内容：

grep head tail wc sort uniq cut tr sed awk diff nl file stat

💡 试试 grep root /etc/passwd 在文件中搜索特定内容。

第3阶段：系统信息与监控（2天）

了解服务器运行状态：

uname hostname whoami id who uptime date free ps top htop kill lsof dmesg

💡 htop 会显示彩色进度条和进程列表；ps aux 列出所有进程。

第4阶段：硬件与磁盘（1-2天）

深入了解硬件和存储：

lscpu lspci lsusb lsblk lshw dmidecode smartctl sensors df du fdisk mount blkid dd

💡 试试 lsblk 查看磁盘树形结构，smartctl -a /dev/sdb 查看坏道硬盘的 SMART 详情。

第5阶段：网络（1-2天）

网络诊断和管理：

ping curl wget ifconfig ip netstat ss nslookup dig traceroute route tcpdump nc ssh scp

💡 在模拟器中 ping -c 5 8.8.8.8 会看到真实的 ICMP 序列号递增和延迟变化。

第6阶段：用户与权限（1天）

Linux 用户管理系统：

chmod chown chgrp umask useradd userdel usermod passwd su sudo

💡 试试 sudo whoami，提示符会变成 #，输出 root。

第7阶段：软件包管理（1天）

安装和管理软件：

apt yum dpkg snap

💡 apt install nginx 会模拟完整的安装过程（Downloading → Installing → Setting up）。

第8阶段：服务管理（1天）

管理系统服务：

systemctl journalctl service crontab

💡 systemctl status nginx 显示详细的服务运行状态。

第9阶段：Shell 编程（2天）

环境变量、别名、脚本：

bash alias env export source tee watch

第10阶段：Vi/Vim 编辑器（1-2天）

终端编辑器：

vi vim vimtutor nano

💡 输入 vi web.conf 会弹出真实的编辑器弹窗！用 i 进入插入模式，Esc 退出，:wq 保存退出。

三、模拟器使用技巧

💡 管道和重定向：支持 | 管道和 > 重定向，但管道操作部分受限于 VFS 机制。例如 cat /etc/passwd | grep root 可以正常使用。
💡 命令链：支持 && 命令链接。例如 cd /tmp && pwd。
💡 Tab 补全：在输入框中按 Tab 可以补全命令或路径。
💡 右侧面板：点击右侧命令可自动填入输入框。
💡 Vi 编辑器：支持 i a o I A O 进入插入模式、h j k l 移动、dd yy p u 编辑、:w :q :wq :q! 退出。
💡 sudo/su：sudo bash 会真正切换到 root 提示符 #，sudo whoami 输出 root。

四、实战练习题

  1. 文件浏览：列出根目录所有文件（含隐藏文件），进入 /var/log，查看 syslog 的前 5 行。 
    ls -la /
cd /var/log
head -n 5 syslog
  2. 文本搜索：在 /etc/passwd 中搜索包含 root 的行，统计该文件有多少行。 
    grep root /etc/passwd
wc -l /etc/passwd
  3. 系统信息：查看系统运行时间、内存使用、CPU 型号和磁盘使用情况。 
    uptime
free -h
lscpu
df -h
  4. 硬件诊断：列出所有块设备，检查坏道硬盘的 SMART 状态，查看内存插槽信息。 
    lsblk
smartctl -a /dev/sdb
dmidecode -t memory
  5. 网络诊断：Ping 百度 DNS，查看网络连接状态，Trace DNS 查询。 
    ping -c 3 114.114.114.114
netstat -tulanp
dig google.com
  6. 用户权限：使用 sudo 查看当前用户，切换到 root 用户，再切回来。 
    sudo whoami
su root
exit
  7. 包管理：更新软件源、安装 nginx、查看 nginx 服务状态。 
    sudo apt update
sudo apt install nginx
systemctl status nginx
  8. 文件编辑：用 vi 打开 /root/projects/web.conf，修改后保存退出，用 cat 确认修改。 
    vi /root/projects/web.conf
cat /root/projects/web.conf
  9. Docker：查看运行中的容器、镜像列表，拉取一个镜像。 
    docker ps
docker images
docker pull alpine
  10. Kubernetes：查看 Pod 列表、节点状态、服务列表。 
    kubectl get pods
kubectl get nodes
kubectl get svc
