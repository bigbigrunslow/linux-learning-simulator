二、11 阶段学习路径

第1阶段：文件操作基础（1-2天）

掌握 Linux 最基本的文件浏览和操作命令，这是所有后续学习的地基。

lscdpwdmkdirtouchcatrmcpmvechofindln
💡 试试 ls -la / 看根目录下有哪些文件（含隐藏文件），然后用 cd /tmp 探索，touch hello.txt 建文件，rm hello.txt 删掉。

第2阶段：文本处理（1天）

学会在终端里搜索、筛选、统计文件内容——运维排障的核心技能。

grepheadtailwcsortuniqcuttrsedawkdiffnlfilestat
💡 grep root /etc/passwd 搜用户；cat /etc/passwd | grep bash 练管道；wc -l /etc/passwd 数行数。

第3阶段：系统信息与监控（2天）

学会“看服务器状态”：内核、内存、进程、负载。

unamehostnamewhoamiidwhouptimedatefreepstophtopkilllsofdmesg
💡 htop 有彩色进度条；ps aux 列出所有进程；kill 5600 后进程真的会从 ps 消失。

第4阶段：硬件与磁盘（1-2天）

深入了解 CPU、内存、磁盘与硬件健康。

lscpulspcilsusblsblklshwdmidecodesmartctlsensorsdfdufdiskmountblkiddd
💡 lsblk 看磁盘树；smartctl -a /dev/sdb 查看坏道硬盘的 SMART 详情；df -h 看剩余空间。

第5阶段：网络（1-2天）

网络诊断和管理：连通性、端口、DNS、远程传输。

pingcurlwgetifconfigipnetstatssnslookupdigtracerouteroutetcpdumpncsshscp
💡 ping -c 5 8.8.8.8 看延迟；ss -tlnp 看监听端口；curl example.com 抓网页。

第6阶段：用户与权限（1天）

Linux 用户与权限模型，理解 root 与 sudo 的意义。

chmodchownchgrpumaskuseradduserdelusermodpasswdsusudo
💡 sudo whoami 输出 root；chmod 600 file 后 ls -l 会显示 -rw-------；普通用户写 /etc 会被拒绝。

第7阶段：软件包管理（1天）

安装、升级、卸载软件。

aptyumdpkgsnap
💡 sudo apt update 刷新源，sudo apt install nginx 模拟完整安装过程，装完用 systemctl status nginx 查看。

第8阶段：服务管理（1天）

用 systemd 管理服务与日志。

systemctljournalctlservicecrontab
💡 systemctl stop/start/restart nginx 会真实改变服务状态；journalctl -u nginx 看服务日志；crontab -l 看定时任务。

第9阶段：Shell 编程（2天）

环境变量、别名、管道、脚本——从“用命令”到“写命令”。

第10阶段：Vi/Vim 编辑器（1-2天）

终端编辑器，服务器上绕不开的工具。

vivimvimtutornano
💡 vi web.conf 弹出真实编辑器：i 插入、Esc 普通、dd 删行、:wq 保存退出；vimtutor 是内置教程。

三、模拟器使用技巧

管道与重定向：cat /etc/passwd | grep root 把上一个命令的输出交给下一个；echo hi > file 写入文件，>> 追加。
命令链：cd /tmp && pwd 前一条成功才执行后一条；|| 反之；; 无条件分隔。
退出码：命令成功返回 0，失败返回 1，用 echo $? 查看。
Tab 补全：输入命令或路径时按 Tab 自动补全。
右侧面板：点击右侧命令可自动填入输入框；分类包括 中间件 / K8s / CI/CD。
Vi 编辑器：i a o I A O 进入插入、h j k l 移动、dd yy p u 编辑、:w :q :wq :q! 退出。
sudo/su：sudo bash 真正切换到 root 提示符 #，exit 退回。
学习功能：practice 跟练、practice path 换项目、exam 考试、stats 统计、guide 本指南、lang 换语言。

四、实战练习题

  1. 文件浏览：列出根目录所有文件（含隐藏文件），进入 /var/log，查看 syslog 的前 5 行。 
    ls -la /
cd /var/log
head -n 5 syslog
  2. 文本搜索：在 /etc/passwd 中搜索包含 root 的行，统计该文件有多少行。 
    grep root /etc/passwd
wc -l /etc/passwd
  3. 系统信息：查看运行时间、内存使用、CPU 型号和磁盘使用情况。 
    uptime
free -h
lscpu
df -h
  4. 硬件诊断：列出所有块设备，检查坏道硬盘的 SMART 状态，查看内存插槽信息。 
    lsblk
smartctl -a /dev/sdb
dmidecode -t memory
  5. 网络诊断：Ping 114.114.114.114，查看网络连接状态，DNS 查询 google.com。 
    ping -c 3 114.114.114.114
netstat -tulanp
dig google.com
  6. 用户权限：用 sudo 查看当前用户，切换到 root 用户，再切回来。 
    sudo whoami
su root
exit
  7. 包管理：更新软件源、安装 nginx、查看 nginx 服务状态。 
    sudo apt update
sudo apt install nginx
systemctl status nginx
  8. 文件编辑：用 vi 打开 /root/projects/web.conf，修改后保存退出，用 cat 确认。 
    vi /root/projects/web.conf
cat /root/projects/web.conf
  9. Shell 脚本：写一个脚本，定义变量并输出，用 bash 执行。 
    echo 'name=Codex' > /tmp/demo.sh
echo 'echo $name' >> /tmp/demo.sh
bash /tmp/demo.sh
  10. Docker：查看运行中的容器、镜像列表，拉取一个镜像，再停掉一个容器。 
    docker ps
docker images
docker pull alpine
docker stop nginx-proxy
  11. Kubernetes：查看 Pod 列表、节点状态、服务列表。 
    kubectl get pods
kubectl get nodes
kubectl get svc

六、常见问题

需要联网吗？ 不需要。模拟器完全在浏览器本地运行，联网命令（ping/curl）输出的是模拟数据。
会弄坏真机吗？ 不会。所有操作都在虚拟文件系统里，刷新页面即可恢复。
进度会丢吗？ 练习进度和语言选择保存在浏览器本地，刷新不丢；想重置用 practice reset。
命令是假的吗？ 输出是模拟的，但管道、重定向、脚本、权限、服务/容器/进程状态都是真实逻辑，适合练手。
想深入学怎么办？ 用 learn 命令 看百科，practice 命令 做专项练习，学完去真实服务器（云主机/WSL）实践。

2. The 11-Stage Learning Path

Stage 1: File Operations Basics (1-2 days)

Master basic file browsing and manipulation — the foundation of everything else.

lscdpwdmkdirtouchcatrmcpmvechofindln
💡 Try ls -la / to explore the root, cd /tmp, touch hello.txt, then rm hello.txt.

Stage 2: Text Processing (1 day)

Search, filter and count file contents — a core ops skill.

grepheadtailwcsortuniqcuttrsedawkdiffnlfilestat
💡 grep root /etc/passwd, then cat /etc/passwd | grep bash for pipes, and wc -l /etc/passwd.

Stage 3: System Info & Monitoring (2 days)

Read the server: kernel, memory, processes, load.

unamehostnamewhoamiidwhouptimedatefreepstophtopkilllsofdmesg
💡 htop shows colorful bars; ps aux lists all processes; kill 5600 really removes the process.

Stage 4: Hardware & Disks (1-2 days)

CPU, memory, disks and hardware health.

lscpulspcilsusblsblklshwdmidecodesmartctlsensorsdfdufdiskmountblkiddd
💡 lsblk for the disk tree, smartctl -a /dev/sdb for SMART details, df -h for free space.

Stage 5: Networking (1-2 days)

Connectivity, ports, DNS and remote transfer.

pingcurlwgetifconfigipnetstatssnslookupdigtracerouteroutetcpdumpncsshscp
💡 ping -c 5 8.8.8.8 for latency, ss -tlnp for listening ports, curl example.com to fetch a page.

Stage 6: Users & Permissions (1 day)

The Linux user/permission model — what root and sudo really mean.

chmodchownchgrpumaskuseradduserdelusermodpasswdsusudo
💡 sudo whoami prints root; chmod 600 file shows -rw------- in ls -l; writing to /etc is denied for normal users.

Stage 7: Package Management (1 day)

Install, upgrade and remove software.

aptyumdpkgsnap
💡 sudo apt update, sudo apt install nginx, then systemctl status nginx.

Stage 8: Service Management (1 day)

Manage services and logs with systemd.

systemctljournalctlservicecrontab
💡 systemctl stop/start/restart nginx really changes state; journalctl -u nginx shows service logs.

Stage 9: Shell Scripting (2 days)

Variables, aliases, pipes and scripts — from using commands to writing them.

bashaliasenvexportsourceteewatchprintfreadtest
💡 bash script.sh runs scripts with x=1, $( ), ;, comments; echo $? shows the exit code.

Stage 10: Vi/Vim Editor (1-2 days)

The terminal editor you cannot avoid on servers.

vivimvimtutornano
💡 vi web.conf opens a real editor: i insert, Esc normal, dd delete line, :wq save. vimtutor is built in.

3. Simulator Tips

Pipes & redirects: cat /etc/passwd | grep root; echo hi > file writes, >> appends.
Chaining: cd /tmp && pwd runs the second only if the first succeeds; || is the opposite; ; just separates.
Exit codes: 0 = success, 1 = failure; check with echo $?.
Tab completion: press Tab while typing commands or paths.
Side panel: click any command to fill the input; categories include Middleware, K8s and CI/CD.
Vi editor: i a o I A O insert, h j k l move, dd yy p u edit, :w :q :wq :q! quit.
sudo/su: sudo bash really switches to the # root prompt; exit returns.
Learning: practice, practice path, exam, stats, guide, lang.

4. Practice Exercises

  1. File browsing: list all root files (including hidden), enter /var/log, view the first 5 lines of syslog. 
    ls -la /
cd /var/log
head -n 5 syslog
  2. Text search: find lines containing root in /etc/passwd, then count the lines. 
    grep root /etc/passwd
wc -l /etc/passwd
  3. System info: uptime, memory, CPU model and disk usage. 
    uptime
free -h
lscpu
df -h
  4. Hardware: list block devices, check SMART of the failing disk, view DIMM slots. 
    lsblk
smartctl -a /dev/sdb
dmidecode -t memory
  5. Networking: ping 114.114.114.114, view connections, DNS lookup for google.com. 
    ping -c 3 114.114.114.114
netstat -tulanp
dig google.com
  6. Permissions: sudo whoami, switch to root, then back. 
    sudo whoami
su root
exit
  7. Packages: update sources, install nginx, check its status. 
    sudo apt update
sudo apt install nginx
systemctl status nginx
  8. Editing: open /root/projects/web.conf with vi, save, confirm with cat. 
    vi /root/projects/web.conf
cat /root/projects/web.conf
  9. Shell script: write a script with a variable, then run it with bash. 
    echo 'name=Codex' > /tmp/demo.sh

  10. Docker: list containers and images, pull an image, stop a container. 
    docker ps

  11. Kubernetes: list pods, nodes and services. 
    kubectl get pods
kubectl get nodes
kubectl get svc

6. FAQ

Do I need the internet? No. Everything runs locally in the browser; network commands output simulated data.
Can it break my machine? No. All operations happen in a virtual filesystem; refresh to reset.
Will my progress be lost? Progress and language choice are saved in the browser; use practice reset to restart.
Are the commands fake? Outputs are simulated, but pipes, redirects, scripts, permissions and service/container/process state follow real logic.
Want to go deeper? Use learn command for the encyclopedia, practice command for drills, then practice on a real server (cloud/WSL).
